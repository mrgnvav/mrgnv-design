# Команды для публикации на GitHub

# 1. Добавьте удаленный репозиторий (замените USERNAME на ваше имя пользователя)
git remote add origin https://github.com/USERNAME/mrgnv-design.git

# 2. Загрузите код на GitHub
git push -u origin main

# 3. Настройте GitHub Pages:
# - Зайдите в настройки репозитория: Settings → Pages
# - Выберите Branch: main / Directory: / (root)
# - Нажмите Save

# 4. Сайт будет доступен по адресу:
# https://USERNAME.github.io/mrgnv-design/
